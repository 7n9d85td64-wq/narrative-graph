## 工作流程

### 步骤1：接收文本并定位关键章节
1. 接收用户投喂的小说文本和辅助信息。
2. 若是长篇（字数>30万字），自动定位"第30章"位置。若全文不足30章，则分析全部。
3. 快速通读前30章，判断"第一个完整故事单元"的结束章节（主角完成首次对反派的直接反击并成功，或首次达成核心目标）。设该章为 `N_end`。若 `N_end` ≤ 30，分析范围为第1章至 `N_end`；若 `N_end` > 30，分析范围为第1章至第30章。若全文不足30章，分析全部章节。

### 步骤2：核实类型标签（双重验证）
根据标签、简介和开篇前5章内容，依次判定：

#### 2.1 核心前提确认
- 主角行为模式为"表面顺从，暗中在规则缝隙里收割" → "欲望的狩猎+双标的胜利"，正确。
- 主角为"公开碾压/推翻一切" → 规则改造者，标记【类型错误，排除】。

#### 2.2 象限确认
- **规则玩家**（表面顺从、内里收割）：标签含重生复仇、穿书精算、真假千金、替身觉醒、扮猪吃虎、精致利己、规则精算、暗中收割 → 保留。
- 其他象限 → 标记【类型错误，排除】或【类型存疑，请人工确认】。

#### 2.3 爽点驱动类型确认（浏览前5章）
- **数值正反馈型**（伤害数字、开箱出金、系统面板） → 保留。
- **信息差碾压型**（主角知道未来，反派不知） → 保留。
- **情感共鸣型**（Pen极高，强情感锚点） → 标记【类型不匹配，排除】。
- **智商压制型**（反转密集） → 保留。
- **混合型** → 标记【类型存疑，请人工确认】。

### 步骤3：识别六池标签组合（强制从知识库检索）
**必须**从知识库中检索以下内容：
- **A池**：检索 `[理论库.第十一章.五池标签框架]` 中的合法取值，并按优先级判定混合。若知识库中无匹配，写"待定"。
- **F池**：从知识库检索 `[交互库.表八.社会形态标签库]`，匹配关键词，取得分最高（≥0.3）的标签。若无匹配，写"待定"。
- **B池**：从知识库检索 `[交互库.表六.五池标签权重表]` 中的B池标签。
- **C池**：从知识库检索 `[理论库.第十一章]` 中的C池类型。
- **D池**：从知识库检索 `[理论库.第十一章]` 中的D池类型。
- **E池**：从知识库检索 `[理论库.附录.冲突类型速查表]`，强度从开篇判断，类型根据高频冲突词确定。

若无法确定某项，标记"待定"，但C池和D池尽量判定，不轻易待定。

### 步骤4：数据清洗
1. 只保留从第1章到"第一单元结束章"或第30章（二者取其短）的正文内容。
2. 删除：作者的话、阅读须知、小剧场、求票、感谢打赏等非正文内容。
3. 保留：书名、作者名、番茄平台标签、简介（作为元数据）。
4. 合并所有段落为连续文本，不保留章节分隔标记。
5. **严禁修改**原文中的任何标点符号、特殊符号、空格、换行。

### 步骤5：去AI化特征统计
对清洗后的正文文本，统计以下特征的出现次数、每千字频率、密度最高段落（前3个）：
- 连续逗号、感叹号连用、问号与感叹号混用、省略号不规范、空格不规范、引号不匹配、破折号不规范、波浪线滥用、句末标点缺失、中英文标点混用。

输出统计表，并给出去AI化判定：
- 偏高：≥15次/千字 → 更接近人类写作特征
- 适中：8-15次/千字 → 特征混合
- 偏低：<8次/千字 → 更接近AI写作特征

### 节点4：代码（归档）
```python
import os, re

def main(llm_output: str) -> dict:
    a = re.search(r'A池[^：:]*[：:]\s*([^\n]+)', llm_output)
    c = re.search(r'C池[^：:]*[：:]\s*([^\n]+)', llm_output)
    e = re.search(r'E池[^：:]*[：:]\s*([^\n]+)', llm_output)
    f_match = re.search(r'F池[^：:]*[：:]\s*([^\n]+)', llm_output)
    b_match = re.search(r'B池[^：:]*[：:]\s*([^\n]+)', llm_output)
    d_match = re.search(r'D池[^：:]*[：:]\s*([^\n]+)', llm_output)
    title_match = re.search(r'书名[^：:]*[：:]\s*[《]?([^》\n]+)', llm_output)
    
    if not all([a, c, e]): return {'status': 'ERR:标签解析失败'}
    
    a_val = a.group(1).strip()
    c_val = c.group(1).strip()
    e_val = e.group(1).strip()
    f_val = f_match.group(1).strip() if f_match else '待定'
    b_val = b_match.group(1).strip() if b_match else '待定'
    d_val = d_match.group(1).strip() if d_match else '待定'
    title = title_match.group(1).strip()[:30] if title_match else 'unknown'
    title = re.sub(r'[\\/:*?"<>|]', '_', title)
    
    pool_dir = f'G:/写作系统/素材/预分析/{a_val}_{c_val}_{e_val}'
    os.makedirs(pool_dir, exist_ok=True)
    
    fname = f'{title}-{a_val}-{f_val}-{b_val}-{c_val}-{d_val}-{e_val}-完成.md'
    path = f'{pool_dir}/{fname}'
    with open(path, 'w', encoding='utf-8') as f:
        f.write(llm_output)
    
    count = len(os.listdir(pool_dir))
    return {'status': 'OK', 'file': fname, 'pool': f'{a_val}_{c_val}_{e_val}', 'count': count, 'path': path}
```
