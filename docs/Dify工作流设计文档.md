# Dify 工作流设计文档 V2.0

## 架构概览

```
预处理引擎（批量一次性）
  未处理/ → 截取+清洗+六池预判 → 预分析/[A]_[C]_[E]/ → 标准化文件

分析引擎（手动触发）
  预分析/ 标准化文件 → 欲望解码器七工序 → 案例库
  触发条件：你查看某三池已达5本 → 手动启动

参数提炼引擎（手动触发）
  同A+C+E ≥5本 → 共性/特性→pending → 你审批 → baseline

生成引擎（随时可用）
  灵感标签 → A→F→B→C→D→E逐步推导→蓝图→正文填充
```

## 工作流〇：预处理引擎（批量一次性）

```
【节点1】扫描输入
  扫描 未处理/ 下所有 txt 文件
  循环处理每本
  ↓

【节点2】单本处理 (LLM + 代码)
  a. 截取：短篇全文 / 长篇前30章（~7-8万字）
  b. 清洗：去除非正文（作者的话、阅读须知、小剧场）
  c. 六池预判 (A/F/B/C/D/E)：
     RAG 检索 Dify KB「叙事理论图谱」标签定义
     A池：按优先级判定（修仙>星际>游戏>废土>古代>现代）
     F池：社会形态关键词匹配（8种+SNC系数）
     B池：剧情驱动模式
     C池：人物驱动类型
     D池：情感线类型
     E池：冲突强度-类型
  d. 标准化命名：[书名]-[A]-[F]-[B]-[C]-[D]-[E]-预处理.md
  ↓

【节点3】归档 (代码节点)
  a. 存入 预分析/[A池]_[C池]_[E池]/ 文件夹
  b. 更新 _批次统计.json
  c. 原文件移入 未处理/已处理/
```

## 工作流一：分析引擎（手动触发）

```
⚠️ 不自动触发——涉及案例库新建、参数库建议等操作

【触发条件】你查看 _批次统计.json，某三池 ready=true → 手动启动

【节点1】输入
  文件夹路径：预分析/[A池]_[C池]_[E池]/
  平台：番茄短篇 / 晋江长篇
  source: human
  ↓

【节点2】循环每本 (LLM + 代码)
  工序一：标签解析（六池+职业匹配+题材合规）
  工序二：全文向量化（逐句8维+离群点 0.4/0.3/0.3）
  工序三：卦象判定（欧氏距离+并置预处理+对宫碰撞）
  工序四：事件拆解（分层聚合FC/SD/憋屈/焊死位置）
     FC分路径阈值：标准≥0.8/跳跃≥0.3/开局≥0.1/过渡≥0.5
  工序五：信息差分析（认知差+期待确定性双机制+K_reader判定）
  工序六：策略匹配（多维MS+向量一致性+策略归类）
  工序七：爆款归因（综合诊断+道德账簿）
  ↓

【节点3】黄金三章诊断 (LLM)
  词级精密诊断
  复核：InfoGap峰值>0.7？动静并置？金手指信号？
  输出：通过/预警
  ↓

【节点4】案例归档 (代码节点)
  通过 → cases/[A]/[A]_[F]_[B]_[C]_[D]_[E]/《书名》_分析报告.md
         + source标签
  预警 → 标记不归档

【节点5】完成汇总
  分析N本 通过M本 预警N-M本
  ⚠️ 不自动触发参数提炼——你来决定
```

## 工作流二：参数提炼引擎（手动触发）

```
【触发条件】你来 WorkBuddy 说：「XX标签组合已达5本，提炼参数」

【节点1】读取分析报告 (代码)
  扫描 cases/ 对应 [A]_[C]_[E] 组合
  仅统计 source=human 样本
  提取工序1-7所有数值参数
  ↓

【节点2】参数更新器 (LLM + 代码)
  CV = 标准差/均值 × 100%
  判定：
    CV ≤ 10% → 共性基准
    10%-20% → 人工确认
    CV ≥ 20% → 特性分支（自动聚类）
  输出：共性基准与特性分支报告
  ↓

【节点3】存入 pending (代码)
  parameters/pending/[A+C+E]_[日期].json
  通知：「新参数建议待审批」

【审批闸门 — WorkBuddy】
  你审 pending 报告：
    「批」 → WorkBuddy 移文件到 baseline/ → Git 提交 → Dify KB 同步
    「否」 → WorkBuddy 删除 pending
    「观察」 → 保留 pending
```

## 工作流三：生成引擎

### 蓝图生成器（六池逐步推导）

```
【节点1】输入
  平台选择 + 灵感：「修仙世界，穿越，地球女子从微末到成仙，有金手指」
  ↓

【节点2】A池·世界观构建
  判定世界类型 → 加载 interaction/world_templates/
  展开：法术体系、境界体系、资源体系
  ↓

【节点3】F池·社会形态
  匹配 8 种社会形态 → 获取 SNC 系数
  ↓

【节点4】B池·金手指
  系统/穿越知识/特殊体质/前世记忆/隐藏背景
  ↓

【节点5】C池·欲望驱动定型
  三选一 → 欲望矩阵四象限推导 → F/Dir嵌套区间 → DS/RS基线
  SNC 调节道德自洽度
  ↓

【节点6】D池·情感线 → 甜宠/虐恋/无CP...
【节点7】E池·冲突 → 强度-类型
  ↓

【节点8】蓝图汇总 (代码 + LLM + RAG)
  查 L2：templates优先 → baseline兜底 → platform参数
  策略匹配：动态加权启发式(W1×FC+W2×DS+W3×EXP+W4随机)
  工序四压力测试 → 锁定策略变体
  输出：完整创作蓝图（焊死节点/SD/情绪配比/InfoGap/卦象序列/可选分支）
```

### 正文填充器

```
【节点1】输入：蓝图 + 小说专属库（可选）+ 状态迁移文件

【节点2】逐块生成循环
  a. 查 L2 → 目标向量 + 卦象约束 + 风格偏移（分象限+平台）
  b. RAG Dify KB → 能量叙事模板 + 微观语言节奏
  c. LLM 生成 → 代码自检（铁律>独特性）
  d. 不通过 → 修正重生成
  ↓

【节点3】状态迁移输出
  每块后：当前阶段/主角状态/向量/InfoGap/伏笔池/道德账簿/下一块目标
  ↓

【节点4】长篇规则：卷末伏笔审计/象限复查/节奏热力图/焊死卷独立判定
```
