# 双电脑同步配置指南

## 概述

支持两台电脑轮换使用，数据同步通过三个通道完成：
- **通道1 — GitHub 私有仓库**：代码、脚本、L2 JSON、DSL工作流
- **通道2 — Syncthing P2P**：Obsidian 笔记、素材文件
- **通道3 — Dify 各独立**：工作流通过 DSL 导入对齐，KB 通过 upload_dify.py 重建

> 数据不会经过任何第三方云端服务器。GitHub 私有仓库仅你可见，Syncthing 端到端加密直连。

---

## 第一步：安装 Syncthing（新电脑）

1. 下载：https://syncthing.net/downloads/ → 选 Windows (64-bit)
2. 解压到 `C:\Syncthing\`，运行 `syncthing.exe`
3. 浏览器自动打开 `http://localhost:8384`
4. 记下「设备标识」（一串长 ID，如 `ABCDEFG-...`）

---

## 第二步：配对两台电脑

在**当前电脑**上的 Syncthing 面板：

1. 点击右下角「添加远程设备」
2. 填入新电脑的设备标识
3. 共享标签页 → 添加文件夹：
   - 文件夹路径：`G:\obsidian文件夹`
   - 文件夹路径：`G:\写作系统\素材`
4. 在「共享」标签里勾选新电脑的设备

在**新电脑**上：

1. 会弹出设备配对请求 → 点「添加设备」
2. 会弹出文件夹共享请求 → 分别接受两个文件夹
3. 设置对应的本地路径（如 `D:\obsidian文件夹`、`D:\写作系统\素材`）

---

## 第三步：克隆 GitHub 仓库

```bash
git clone https://github.com/7n9d85td64-wq/narrative-graph.git
cd narrative-graph
```

如果之前没配置过 Git 凭证：
```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

> 私有仓库需要 GitHub Personal Access Token。如果 token 过期，在 GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) 生成新的，勾选 `repo` 权限。

存储凭证（只需一次）：
```bash
git config --global credential.helper store
# 下次 git push/pull 时输入用户名+token，会自动记住
```

---

## 第四步：安装 Docker Desktop + Dify

1. 下载 Docker Desktop：https://www.docker.com/products/docker-desktop/
2. 安装后启动
3. 克隆 Dify：
```bash
git clone https://github.com/langgenius/dify.git
cd dify/docker
cp .env.example .env
docker compose up -d
```
4. 访问 `http://localhost`，初始化管理员账号

---

## 第五步：配置 Dify

### 5.1 配置 Embedding 模型

设置 → 模型供应商 → SiliconFlow → 添加 API Key → 选择 `BAAI/bge-large-zh-v1.5`

### 5.2 创建知识库

知识库 → 创建知识库 → 名称：「叙事理论图谱」→ 嵌入模型选 SiliconFlow

### 5.3 上传 L2 知识图谱

```bash
cd narrative-graph
python scripts/upload_dify.py
```

### 5.4 导入工作流

工作流 → 导入 DSL → 选择 `narrative-graph/workflows/` 中的 `.yml` 文件

---

## 第六步：配置 WorkBuddy 项目

直接打开 WorkBuddy，对话窗口里告诉 AI：「新电脑，开始配置」。AI 会自动：
- 检查环境
- 安装 Python 依赖
- 连接服务

---

## 日常使用流程

| 场景 | 操作 |
|------|------|
| 换电脑前 | `cd narrative-graph && git push`（推送最新改动）|
| 换电脑后 | `cd narrative-graph && git pull`（拉取最新改动）|
| Obsidian 笔记修改 | Syncthing 自动同步（开机即同步）|
| L2 JSON 有新节点 | `git pull` → `python scripts/upload_dify.py` |
| Dify 工作流有改动 | 导出 DSL → 放 `workflows/` → `git push` |

---

## 故障排查

### Syncthing 不同步
- 确认两台电脑都在线
- 确认文件夹状态为「已同步」
- 检查防火墙是否放行 Syncthing（端口 22000）

### GitHub push 失败
- Token 是否过期：GitHub → Settings → Developer settings
- 重新生成后更新凭证：`git config --global --unset credential.helper && git config --global credential.helper store`

### Dify KB 上传失败
- 确认 Embedding 模型已配置
- 确认 `upload_dify.py` 中 API URL 正确
- 检查 Docker 容器是否全部运行：`docker ps`
