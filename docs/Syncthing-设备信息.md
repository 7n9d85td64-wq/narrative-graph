## 新电脑配对步骤
1. 在新电脑上安装并启动 Syncthing
2. 在新电脑 Syncthing 面板 → 添加远程设备 → 输入上方设备 ID
3. 在当前电脑 Syncthing 面板确认配对请求
4. 在新电脑上添加对应的文件夹路径（可以是不同盘符，如 D:\obsidian文件夹）
5. 等待首次同步完成
